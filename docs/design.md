# Paper Tabs 设计约定

模式：Redesign · Preserve。将已确认的首页提炼为独立模板。

保留米白横线纸、中央像素标题、两侧胶带小画、彩色身份标签、随滚动叠放的文件夹与联系便签。改善固定项目数量与内容替换方式。单页首页的三个区域保持为个人介绍、精选项目、关于与联系。

设计读法：面向用 AI 或少量代码维护个人主页的创作者；风格是纸张拼贴与手账。视觉变化 5/10、动效 3/10、信息密度 4/10、素材依赖 4/10、原设计保真 9/10。保留布局、轻微旋转和层叠手感，用原创插画替换私人素材，不增加装饰性功能面板。

叙事从“我是谁”到“我做什么”再到“如何联系”。以手机近距离和桌面阅读为主，温暖、轻松；标题是视觉焦点，正文自然换行。桌面容器 1080px，纸张 1360px；间距以 4/8px 为步进。纸片使用直角，头像和印章使用圆形。阴影模拟轻薄纸张，避免厚重悬浮感。

颜色与字体的唯一调整入口是 `theme.css`。米白纸底、近黑文字，黄、蓝、薄荷绿和灰紫用于原有文件夹顺序。标题使用本地 Jersey 10，正文使用系统中文字体；正文不发起字体网络请求。悬停动效 180–240ms，遵循系统减少动态效果设置。

文件夹根据真实高度决定能否叠放：所有卡片必须完整容纳在当前视口，且每个标签至少 48px 宽。长文本、矮屏幕或减少动态效果时自然排列。标签点击置顶，滚动或 Escape 清除选择；左右方向键与 Home/End 支持标签切换。项目跳转使用卡片中的独立链接。

布局适配范围为 1–8 个项目；头像、两张装饰、封面、履历、邮箱、社交和作品集下载均可省略。无 URL 的项目显示示例标记；不创建虚假的详情页或跳转。
