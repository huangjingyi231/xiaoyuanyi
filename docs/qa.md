## 复现

网站本身无需安装任何依赖。以下依赖仅用于维护者运行浏览器检查，需要本机安装 Chrome 和 Node：

```sh
npm install --no-save --package-lock=false playwright
python3 -m http.server 4173 --bind 127.0.0.1
```

另开终端，在项目根目录运行：

```sh
node scripts/browser-check.cjs
```

报告和截图写入被忽略的 `.local/`。脚本为每个场景临时拦截内容配置，不会改动 `content.js`。也可以只执行 `node scripts/check.mjs` 做静态配置检查。

## 验证边界

这次使用真实 Chrome 引擎，没有验证 Safari、Firefox 或真实手机硬件。英文场景主要检查排版，首版未提供一键语言切换。陌生人独立建站目标需要发布后收集真实使用结果；不能由本地测试代替。
