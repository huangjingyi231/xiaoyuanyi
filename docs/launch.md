# 发布文案与试用反馈

## 可直接使用的发布文案

做了一个免费的个人主页模板，叫 **Paper Tabs · 纸页标签**。

它看起来像一本手账：横线纸、像素标题、彩色文件夹和一张联系便签。适合想展示设计、开发、写作或个人项目的人。

换掉一份内容配置，就能放上自己的名字、介绍和 1–8 个作品。没有框架和运行时依赖，可以直接打开，也可以部署到静态网站托管服务。附中文说明和一段能直接交给 AI 的修改指令。

代码采用 MIT，免费，允许商用，网页署名自愿。欢迎试用并告诉我哪里卡住了。

演示：https://paper-tabs.vercel.app

仓库：https://github.com/chingz0509/paper-tabs

1. 从获取模板到上线，你用了多久？你的站点链接是什么？
2. 哪一步卡住了？当时看到什么提示？
3. 是否需要原作者替你改代码？如果有，具体是哪一步？
4. 你用手动修改还是 AI？哪段说明最有帮助，哪段不清楚？
5. 你展示了几个项目？手机上有没有文字、图片或链接问题？
6. 你最希望下一版改进哪一件事？

## 成功标准

至少 3 位与作者无关的使用者，在作者不代改代码的情况下独立上线自己的版本。记录匿名编号、完成日期、授权公开的链接、用时、卡点、是否需要作者介入。未经许可不公开参与者个人信息。
